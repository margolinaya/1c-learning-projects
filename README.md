# 1c-projects

# Учебные проекты по 1С:Предприятие

Репозиторий с моими учебными проектами по разработке на платформе 1С:Предприятие 8.3 и 8.5.

---

## Проекты

### [Обмен с RetailCRM для 1С:Управление торговлей](./retailcrm-exchange/)
Учебное расширение для 1С:УТ, разработанное в рамках тестового задания на позицию 1С-разработчика.

- **Платформа:** 1С:Предприятие 8.5
- **Конфигурация:** 1С:Управление торговлей
- **Тип проекта:** Расширение конфигурации
- **Интеграция:** REST API RetailCRM, HTTP-запросы, JSON
- **Настройки обмена:** Адрес CRM, API-ключ, код магазина, организация и склад
- **Загрузка заказов:** По идентификатору и дате создания
- **Работа с номенклатурой:** Сопоставление товаров по артикулам
- **Обработка ошибок:** Проверка ответов API и обработка ошибок обмена

---

### [Тайм-Трекер](./timetracker/)
Учёт времени по задачам и проектам.
- **Документы:** Регистрация времени
- **Регистры:** Учёт времени по задачам
- **Отчёты:** Сводка по задачам, детализация по дням
- **Обработка:** Таймер для засечения времени

---

### [Учёт бюджета](./budget/)
Учёт личных финансов с план-факт анализом.
- **Справочники:** Статьи бюджета, счета
- **Документы:** Операции, план бюджета
- **Регистры:** Остатки денег, факт и план бюджета
- **Отчёты:** Остатки по счетам, план-факт

---

## Используемые механизмы платформы 1С

- Справочники, документы, регистры накопления и сведений
- Запросы, в том числе с соединениями и временными таблицами
- Система компоновки данных (СКД)
- Управляемые формы, обработчики на клиенте и сервере
- Расширения конфигурации
- HTTP-сервисы и HTTP-запросы для интеграции с внешними системами
- Чтение и обработка JSON
- Работа с REST API внешних систем

---

## Цель проекта

Закрепление практических навыков разработки на 1С, изучение механизмов интеграции с внешними системами и создание портфолио для дальнейшего трудоустройства.

## Статус

Проекты учебные, находятся в процессе изучения и доработки.
